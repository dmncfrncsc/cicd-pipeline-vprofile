### Preliminary AWS price comparison (official pricing pages checked 2026-10-09; planning only)

Assumptions: `us-east-1`; Linux On-Demand T3 instances; 730 compute hours for an average month; and an illustrative 48-hour run. The sizes and storage volumes below are examples only, not approved or tested capacity. Estimates are before credits and taxes. They exclude T3 surplus CPU-credit charges, backups/snapshots, NAT data processing and internet transfer unless stated, S3 requests, and any extra security services.

| Example | Compute per hour | 48 hours | 730 hours | Memory |
| --- | ---: | ---: | ---: | ---: |
| One `t3.large` | $0.0835 | $4.01 | $60.96 | 8 GiB |
| Four `t3.small` | $0.0836 total | $4.01 total | $61.03 total | 8 GiB total (2 GiB each) |

This compute-only example shows that one instance is not automatically cheaper: these two cases cost nearly the same for compute. The four-instance case has more total vCPUs, and its RAM is split across four hosts; neither configuration has been checked for VProfile's memory or CPU needs. AWS lists T3 On-Demand Linux prices for `us-east-1`; T3 Unlimited can add CPU-credit charges when applicable.

At the AWS gp3 example rate of $0.08/GiB-month, a placeholder 20-GiB root volume costs about $1.60/month for one host or $6.40/month for four. For 48 hours, the prorated amounts are about $0.11 and $0.43. EBS storage continues to bill while an instance is stopped and until the volume is released. A single 83,278,692-byte WAR is about 0.0776 GiB; at the S3 Standard first-tier rate of $0.023/GB-month, that is about $0.0018 per retained copy per month, before requests. Retaining more versions multiplies the stored data.

For one shared NAT Gateway in one Availability Zone, the AWS pricing example rate is $0.045 per gateway-hour plus $0.045 per GB processed. One public IPv4 address adds $0.005 per address-hour. At those rates, 48 hours costs $2.16 for gateway hours plus $0.24 for its IPv4 address ($2.40 fixed, before processing and internet data transfer); 730 hours costs $32.85 plus $3.65 ($36.50 fixed). The NAT example on AWS's pricing page is for Ohio, so confirm the exact N. Virginia quote in the AWS Pricing Calculator before approval. If using interface endpoints instead, the current example rate is $0.01 per endpoint ENI per hour and $0.01 per GB processed; three endpoints in one AZ would be $1.44 for 48 hours or $21.90 for 730 hours, before processing. The required endpoint count is unconfirmed, and endpoints do not provide package-site internet access. In the public-subnet fallback, public IPv4 costs $0.005 per address-hour: one address is $0.24 for 48 hours or $3.65 for 730 hours; four addresses are $0.96 or $14.60. No inbound rules do not remove this address charge.
